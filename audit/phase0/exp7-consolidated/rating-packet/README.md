# Review procedure and remaining gaps

Send only reviewer-packet.md and a blank copy of rating-form.csv to each reviewer. Keep answer-key.json separate with the coordinator. No contacting raters is authorized or performed. Case order is deterministic hash order; A/B positions are balanced three each. Answers are byte-preserved, with no model/variant labels or prior assistant scores in the reviewer packet. Text itself can reveal condition, so claim partial label blinding only. The evidence is the same eligible corpus for both answers, not variant-specific retrieved context; score end-to-end accessible-evidence grounding. Restricted fictional sources are evaluator leakage references only. Two independent reviewers plus recorded adjudication are recommended, not completed.

Protocol deviation: five tail answers were generated after a terminal harness stop without renewed authorization; all original outputs and ledgers remain preserved. Human scoring cannot cure that procedural deviation. All results remain exploratory/unvalidated. No new provider calls.

Repeatability: only one valid output per case/variant (12 outputs, six pairs); no independent second repeat exists for any pair. The earlier failed generation/HTTP400 and local rank replay are not repeats. Re-scoring or replaying saved outputs cannot measure model output variance. A fresh paired rerun would need separate explicit authorization and a revised frozen protocol; this packet authorizes none. Model fingerprints varied, and responses were collected across sessions/repairs. Human naturalness/style scores, independent grounding review, inter-rater agreement and adjudication remain pending; billing and first-token timing remain unmeasured. No real-person fidelity claim.
