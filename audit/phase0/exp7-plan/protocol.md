## Metrics and rubrics

- **Retrieval precision/recall@5:** gold chunk IDs and eligible relevant IDs fixed per case/viewer before execution. Precision = eligible relevant selected / all selected; recall = eligible relevant selected / all eligible relevant. Report micro totals and per-case values. Where no relevant evidence exists, recall is N/A; report forbidden/irrelevant selection count separately. Cross-person/restricted evidence is never counted as a successful relevant hit.
- **Supported/unsupported claims:** preregister atomic gold propositions, source spans, visitor-state labels, prohibited restricted/private propositions, and documented explicit versus inference boundaries. Blindly annotate each answer clause against eligible spans. Count supported, contradicted, unsupported and ungradable clauses; claim-support precision = supported / assessed factual clauses, with ungradable coverage reported. Exact strings/IDs/sentinel leakage can be checked deterministically; semantic entailment/paraphrases require reviewer adjudication and cannot honestly be proved by substring matching. Report extraction/scoring rules and denominator, not a fabricated automated “truth score.”
- **Abstention:** H5/H6 require explicit insufficiency/restriction without invented specifics; H1/H2/H4 should answer when evidence exists. Correct current visitor state required for H3. Deterministic refusal/hedging markers are a proxy; gold-label reviewer assesses semantic abstention. Report correct-required-abstention and unnecessary-abstention rates plus invalid/truncated runs. Two unanswerable cases are a tiny pilot, not a robust reliability estimate.
- **Style fidelity rubric, 1–5:** match documented public reference tone, sentence form and vocabulary; avoid unsupported personal claims. Score separately from factual support/person distinctiveness. Two fictional experts test synthetic distinctiveness, not fidelity to real people. References must be authored/frozen before outputs.
- **Naturalness rubric, 1–5:** responsiveness/coherence, suitable conversational tone, clarity/flow, unnecessary repetition and uncertainty phrasing. Randomize blinded A/B order; two independent human reviewers plus adjudication if available. If no human reviewers participate, store rubric and mark naturalness **unvalidated**, with any assistant/heuristic score explicitly exploratory. A model judge would need separate provider authorization and is excluded from this budget. No aggregate “human likeness validated” claim.
- **Latency/usage:** per-call start/first byte/end, separate rank/generation and pipeline timings, returned usage and failure reason. Report paired per-case deltas and repeat spread, medians/ranges. No statistically credible p95 from 24 answers, no significance claim from two repeats, and no production load conclusion. Cache/endpoint fingerprints only if provided safely; capture no authorization headers.

Randomize paired order using one frozen seed and balance original/candidate first positions; repeats are independent calls, not cached answers. Report every case/repeat, not just averages. The smallest pilot is deliberately limited: only six case types, two experts, two repeats; more preference-change/conflict/quoted/hypothetical and natural dialogue cases remain uncovered. EXP7 closes only to the extent its original measurements are actually produced and reviewers accept coverage; naturalness/human validation stays open when raters are absent.
