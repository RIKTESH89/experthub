The 7000-point groove particle layer is allocated but hidden throughout; anatomical mesh grooves remain. The user-selected material from ExpertHub-dark-brown-black.png uses near-black recesses and deep brown glossy highlights. Its exact mesh parameters are retained in art/accepted-material.js; shader highlight colour, diffuse/occlusion floors and edge intensity are now tunable uniforms. Accessory threads/particles use coordinated subdued brown/black, normal blending and reduced sparkle brightness. The homepage keeps its warm dark background and beige text through server markup, loading, static reading and renderer-failure fallback. The shared app theme preference remains unchanged. Full renderer cost and output differ from the source's simpler tower lighting/fog. DPR budgets remain1.35phone/1.65desktop and2.5million pixels; no FPS-parity claim. Active rendering follows browser cadence; pauses outside the story/hidden tab.

6. **Accessibility and lifecycle:** the warm dark loading screen covers normal JavaScript story content until the first successful brain draw and a paint opportunity; asset fetch completion does not reveal it. There is no percentage or progress bar. OS reduced motion and short landscape viewports automatically use the actual renderer poster, waiting for decoded nonzero pixels before reveal; reduced motion disables loader animation. The accessible skip-to-story link uses the same decoded poster path. A20-second deadline, asset/decode/draw failures and context loss keep a clear error/retry screen with navigation available. Attempt ownership and abort cleanup prevent late work from revealing an obsolete attempt. Owned GSAP context/timelines/SplitText/ScrollSmoother are disposed on preference/route/error/unmount and partial setup failures; aborting font readiness rejects promptly; no global trigger kill. Scroll locking is scoped to a connected pending homepage, with cleanup restoring owned inert/tabindex state. NoJS shows the illustrated semantic story without the loader. Without JavaScript, native image failure cannot offer decoded gating or an interactive retry; the image description and text remain accessible. The source's arbitrary1.5-second loader and optional study audio are omitted.

Source-engine/configuration parity and readable framing require separate browser checks. This document describes the implementation, not subjective smoothness or physical-device performance guarantees.
