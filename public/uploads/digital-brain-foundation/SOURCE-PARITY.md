## Explicit changes and limitations

1. **Artwork and palette:** one unchanged detailed Versal brain with the Sahil shaders,7000 groove points,120 curved threads,480 thread particles,2000 sparkles and postprocessing replaces the tower. Warm ivory/clay/brown/charcoal colors replace forest/copper. Full renderer cost and output differ from the source's simpler tower lighting/fog. DPR budgets remain1.35phone/1.65desktop and2.5million pixels; no FPS-parity claim. Active rendering follows browser cadence; pauses outside the story/hidden tab.
2. **Coordinate retarget:** source tower conservative geometry bounds at scale3 are(5.572935379,25.891032126,7.321799978), center(−.026283455,13.272128812,.317969838). Brain bounds are(1.058489323,1.123886704,1.316222429), center(.004501224,−.077294290,.049499929). Target points use `brainCenter + (target − sourceCenter) * brainSize/sourceSize`. Camera points use `mappedTarget + (sourceCamera − sourceTarget) * scale`, with constant scale0.091506602021 multiplied by `clamp(1/aspect,1,1.5)` for the current viewport. This preserves every source viewing direction, pitch and camera-to-target distance ratio within a viewport. The original overhead pitch is64.760598° in both scenes. Absolute distances, target positions, camera translation and pixel framing change for the compact illustration. No per-shot fit clamp or view offset. Near/far.01/100 accommodate brain units instead of original1/1000.
3. **Copy and typography:** short ExpertHub titles/subtitles replace source copy; the seven full required headings and explanations remain in the semantic static story. Non-whitespace character counts differ by at most6 per visible slot. With the original stagger, estimated total timeline-duration differences are at most0.16seconds (the character count still affects cadence). The installed Geist font replaces the Adobe source font. Desktop4vw title and source weight/leading remain; subtitle uses `max(16px,1.25vw)` to preserve reading size. SplitText uses the unchanged source `{type:"chars"}` option. Warm-palette shadows and subtitle color protect legibility over the material.
4. **Phone text bounds:** vertical placements remain source-derived. Source mobile full-width plus20vh/80px horizontal offsets clip longer copy, so widths are bounded to viewport minus48px; left placement uses24px; bottom-left uses left48/right24, bottom-right uses right48/left24. Top-left/top-right retain source25vh/24px mobile positions. Subtitle minimum16px applies at all widths; on phone it replaces the source's inherited12px `text-l` typo. These are deliberate readability deviations, not pixel-identical phone typography.
5. **Application:** ExpertHub navigation and real actions replace the Codrops study frame. Pricing/application/footer follow the cinematic spacer inside content. No study links. App fragment links use the official ScrollSmoother.scrollTo API for an immediate, correctly offset jump, with history preserved; native Next hash offsets are incorrect inside transformed content. Semantic static story retains all seven required headings and real CTAs. Sample question/answer are clearly fictional/scripted; citations are not a correctness guarantee and source corrections are manual.
6. **Accessibility and lifecycle:** reduced motion/noJS/error/static story, skip-to-story/history fixes and actual loading readiness remain. Owned GSAP context/timelines/SplitText/ScrollSmoother are disposed on mode/route/error/unmount and partial setup failures; aborting font readiness rejects promptly; no global trigger kill. The original arbitrary1.5-second loader and optional study audio are omitted. These changes protect existing app use rather than claiming literal source-code identity.

Source-engine/configuration parity and readable framing require separate browser checks. This document describes the implementation, not subjective smoothness or physical-device performance guarantees.
